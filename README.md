# 🤖 Fat-Boy AI

> ### *"Empowering Conversations with Artificial Intelligence"*

---

## ✨ About The Project

**Fat-Boy AI** is a modern, sleek, and responsive AI chat interface inspired by Groq and ChatGPT. Built with cutting-edge web technologies, it provides an immersive conversational experience with AI-powered responses.

---

## 🎯 Features

| Feature | Description |
|---------|-------------|
| 🎨 **Modern UI** | Beautiful dark-themed interface with gradient animations |
| 💬 **Real-time Chat** | Instant AI responses with smooth typing animations |
| 🌙 **Dark/Light Mode** | Toggle between themes for comfortable viewing |
| 📱 **Fully Responsive** | Works perfectly on desktop, tablet, and mobile devices |
| 📋 **Copy Response** | One-click copy functionality for AI responses |
| 🔄 **Conversation Memory** | Maintains context throughout the chat session |
| ⚡ **Fast & Lightweight** | Optimized performance with minimal load time |
| 🧠 **Deep Think Mode** | Toggle for step-by-step detailed AI responses |

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Edge, Safari)
- Internet connection (for API and CDN resources)

### Installation

1. **Clone or Download** the repository
   ```bash
   git clone https://github.com/yourusername/fat-boy-ai.git
   ```

2. **Open** `chat-gpt.html` in your browser

3. **Start Chatting!** Type your message and press Enter or click Send

---

## 💡 How To Use

| Step | Action |
|------|--------|
| 1️⃣ | Open the application in your browser |
| 2️⃣ | Enter any username to continue (localStorage) |
| 3️⃣ | Type your question or prompt in the input field |
| 4️⃣ | Press **Enter** or click the **Send** button |
| 5️⃣ | Wait for the AI response to appear |
| 6️⃣ | Use **📋 Copy** to copy the response |
